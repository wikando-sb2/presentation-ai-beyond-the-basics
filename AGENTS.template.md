# Template Instructions

Use these instructions when the remote repository is `wikando/slidev-template`.

This repository is the shared Slidev template. 
Changes should improve the reusable foundation for future presentations.

- Keep template changes generic and reusable across presentations.
- Avoid adding presentation-specific slides, copy, assets, or branding unless they are intentional examples.
- Preserve stable APIs for layouts, components, theme styles, snippets, and package configuration.
- When changing reusable components or layouts, consider how existing presentations based on the 
  template may be affected.
- Prefer clear theme structure and maintainable defaults over one-off customization.
